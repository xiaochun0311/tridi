# TriDi 双曲空间接入分析与远程接触实验

日期：2026-10-14。远程仓库：`/home/yanghc/tridi`；分支：`manifold-test`；提交：`86e0e9de1c63acb87d41cba2540863f45ac0e04c`。

本轮已经通过 Trae 的远程终端运行真实数据训练。结论是：接触特征和语义条件可以作为双曲空间的实验入口，但本轮接触重建对照没有观察到双曲优势，不建议直接替换原模型。完成的是独立接触编码实验，不是完整双曲扩散模型，也未验证人体生成质量。

不建议直接改成双曲表示的部分：人体/物体 XYZ、真实接触距离、人体关节旋转、物体刚体位姿。它们分别自然对应欧氏几何、旋转空间 SO(3) 和位姿空间 SE(3)。

从动机看，明确层级的类别/语义条件优于没有结构监督的接触向量；从当前可执行性看，接触编码最容易隔离并做公平对照。因此，本轮先验证接触编码，未人为构造物体类别树来宣称效果。

## 2. 执行范围与数据

- 操作对象为 Trae 中连接 `172.18.4.107` 的实际远程仓库；使用已有 `tridi-offline` Python 环境。
- 两张 GPU 已有其他工作负载。本轮全部使用 CPU、两个 PyTorch 线程，没有停止已有任务或安装依赖。
- GRAB 数据覆盖实际可用的 20 个物体；训练 s1–s6，验证 s7–s8，测试 s9–s10，主体不重叠。
- 训练 2,033 帧、309 个序列；验证 821 帧、127 个序列；测试 587 帧、110 个序列。训练/验证从 10 fps 数据每 10 帧取一帧，测试使用现有 1 fps 数据。
- 标签由 690 个采样人体顶点到物体规范关键点经旋转、平移后的最近距离得到，阈值为 0.05。首次帧核对 KDTree 与 `torch.cdist`，距离及接触掩码一致；本轮所有抽取帧的 `prep_s` 都为 1。
- 训练标签阳性比例约 1.27%，测试约 1.18%；测试平均 8.14 个接触顶点，104 帧无接触。因此主要报告 F1/IoU，而非容易被大量阴性顶点抬高的准确率。
- 物体类别在训练和测试之间重叠，本轮检验跨主体重建，不是未见物体泛化。

标签沿用当前关键点接触定义，并不是真实连续表面的精确接触，也不是穿透标签。

## 3. 实验方法与公平性

每个模型训练 600 次参数更新，batch size 128；随机种子 42、43、44；Adam 学习率 0.002；相同的训练批次序列。使用带阳性权重的 BCE，权重仅从训练数据计算，上限 20。每 100 步在验证集上评估，接触概率阈值从 0.05–0.95 的固定网格选择。检查点和阈值都按验证集 F1 选择，测试集不参与此选择。

### 第一轮：距离原型解码器

欧氏和双曲模型使用相同 ContactEnc、相同 16 维潜变量和 690 个可学习顶点原型，以到原型的距离预测接触。两个模型参数量相同。欧氏平方距离乘 4，匹配庞加莱模型在原点的局部度量尺度。

两者都退化成接近固定的接触预测：所有测试帧均预测 12 个接触顶点，平均 F1 为 37.37%。同维度 MLP 参考的 F1 为 87.02%，但其参数量更多，不能将这个架构差异当成双曲几何本身的劣势。

因此保留失败结果，并开展第二轮，消除距离解码器结构的影响。

### 第二轮：相同 MLP 上的距离辅助约束

比较三种方案：

1. 原有 ContactEnc/ContactDec 架构，仅使用接触重建损失。
2. 相同架构，加欧氏潜在距离辅助约束。
3. 相同架构，加双曲潜在距离辅助约束。

三者在每个维度上参数量相同，编码器和解码器初始权重一致。分别测试 16 维和与 TriDi 原配置一致的 128 维。16 维每模型 979,138 个参数；128 维每模型 1,036,594 个参数。

令编码器输出为 z，双曲点为 `expmap0(0.1*z)`，固定曲率 -1。辅助损失拟合几何距离平方与接触集合 Jaccard 距离平方：

`L = weighted_BCE + 0.03 * mean((d² - (1-IoU)²)²)`

训练批次中使用循环移位配对；两帧都为空接触集合时，目标距离为 0。欧氏对照采用相同缩放和原点局部尺度。辅助权重和尺度为固定试验值，没有做超参数搜索。

解码器仍在切空间坐标上工作；双曲几何通过辅助距离损失影响编码器。这是混合的度量正则化，不是仅添加互相抵消的 Exp/Log 操作，也不是双曲布朗运动或完整黎曼扩散。

原有架构参考在本轮从头训练，并使用 BCE/logits 解释；不是官方预训练 `gb_contacts.pth` 的性能评估。实验检查点格式也不同，不能直接覆盖该资产。

## 4. 最终结果

以下为三个种子的测试指标平均值，数值越大越好。

| 表示维度 | 方案 | 接触 F1 | 接触 IoU |
|---|---|---:|---:|
| 16 | MLP 重建基线 | 87.02% | 77.03% |
| 16 | MLP + 欧氏距离约束 | 87.07% | 77.11% |
| 16 | MLP + 双曲距离约束 | 86.89% | 76.83% |
| 128 | MLP 重建基线 | 86.29% | 75.89% |
| 128 | MLP + 欧氏距离约束 | 86.25% | 75.83% |
| 128 | MLP + 双曲距离约束 | 85.36% | 74.46% |

16 维双曲相对基线下降约 0.12 个百分点；128 维下降约 0.93 个百分点。本轮没有支持采用当前双曲辅助约束的证据。128 维相对欧氏辅助对照在三个种子上均较低，但样本、种子和训练预算有限，未进行显著性检验，不能推出所有双曲方法都无效。

16 维比 128 维表现更好，也不能据此宣布压缩维度越低越好：各模型的训练收敛和超参数仍需单独研究。

## 5. 验证与限制

- 三组实验共完成 27 次训练，均写出 `completed=true`；训练损失和梯度检查通过。
- 几何自检覆盖：到原点距离、距离对称性、相同点距离、球内约束、有限梯度，以及与欧氏局部尺度的一致性。
- 双曲辅助模型测试潜变量没有达到 0.99 半径，未观察到边界饱和。
- 每轮完成时校验原 `tridi/**/*.py`、配置文件和 `.gitignore` 的 SHA256，均保持不变。
- 原模型资产和已有实验检查点未被写入。第一轮源脚本额外保存在其输出目录，避免后续脚本扩展影响追溯。
- 帧之间相关，不能把 587 帧当作 587 个独立交互实验。
- 本轮只评价接触自编码重建，未评价完整人体生成、物体位姿生成、穿透或生成多样性。
- 没有显式树状监督；Jaccard 相似性不等于层级关系。因此，不能把这些实验当成“层级双曲语义模型”的验证。
- 第一轮暴露退化后调整方法，本报告属于探索性实验，后续确认性实验应采用额外独立数据。

## 6. 对后续工作的建议

当前保留原 TriDi 接触编码与扩散配置。更有依据的双曲后续方向是：

1. 获得明确物体功能/动作类别层级后，在类别条件位置实验双曲嵌入。
2. 恢复人体部位分割资产，建立接触—文字配对数据，再比较同维度欧氏与双曲对齐目标。
3. 如果接触特征对照获得稳定收益，再训练匹配新潜变量分布的 TriDi，并比较完整生成质量。

即使保持 128 维，更换接触编码器也会改变潜变量分布，旧扩散检查点不自动兼容。新 decoder 若输出 logits，接触包装器还需明确 sigmoid/阈值处理。完整接入时必须一起核对训练、采样、文字条件、解码和接触引导。
