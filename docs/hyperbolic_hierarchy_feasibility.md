# SMPL-H 骨架层级表示实验（服务器验证）

服务器：172.18.4.107 / bjutcg；项目：/home/yanghc/tridi。

实验读取实际 SMPLH_MALE.pkl 的 52 关节父子树，比较单位边长的最短路径距离表示。它不测量人体物理距离，也没有训练或评估 TriDi 姿态生成。

训练 816 对（包括全部 51 条骨架边），验证 255 对，测试 255 对。两种空间使用相同划分、维度、初始化种子与训练预算；每种尝试学习率 0.01、0.05，各 2000 步，每 100 步仅按验证误差选模型。曲率固定 -1，双精度，CPU 两线程。

| 维度 | 欧氏测试 RMSE（均值 ± 样本标准差） | 双曲测试 RMSE |
|---|---|---|
| 2 | 1.572895 ± 0.333112 | 3.372774 ± 0.213720 |
| 4 | 0.748001 ± 0.022679 | 0.120329 ± 0.004155 |
| 8 | 0.526969 ± 0.019830 | 0.067657 ± 0.000015 |

4/8 维的误差约下降 84%/87%；2 维表现较差。该结果支持继续测试骨架层级特征，但不等同于生成质量提高。

第一轮直接优化 Lorentz 空间坐标，拟合较差；完整结果保留在 outputs/hyperbolic-hierarchy-20261015。第二轮改为切空间坐标经指数映射到 Lorentz 双曲面，结果位于 outputs/hyperbolic-hierarchy-tangent-20261015。第二轮是看到第一轮结果后的探索性改进，不是预注册实验。

检查：父子树连通、解析径向距离、有限梯度、独立庞加莱公式交叉验证均通过；服务器复核脚本读取 18 份保存的嵌入，重算测试误差与 JSON 一致。训练期间 tridi/**/*.py 与 config 目录文件哈希不变。

限制：只是一棵固定树、一个关节对划分、三个初始化种子；全部关节和骨架边在训练中已知，留出的距离也可从树直接推导，因此测量的是低维压缩的距离保真度，不是新关节或新人体的泛化。单独的对称距离也不编码父子方向，需要另加根节点/深度。没有物体部件层级数据，也未进行动态姿态、接触、穿模或生成质量验证。

建议下一步对照：同一逐关节姿态模型使用欧氏层级特征、双曲层级距离偏置、直接树距离偏置；必须保留直接树距离这一简单基线。现有 TriDi 把姿态压为单个 token，仅拼接静态向量可能被偏置吸收，不能据此证明层级建模有效。
